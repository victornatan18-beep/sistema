Configurar Lojas

Conecte suas duas lojas Shopify para ativar o redirecionamento

📋 Como obter as credenciais do Shopify

  1. Acesse o Admin da loja → Configurações → Apps e canais de vendas
  2. Clique em Desenvolver apps → Criar app
  3. Em Configuração de API Admin, habilite: read_products, read_inventory
  4. Em Configuração de API Storefront, habilite: unauthenticated_read_product_listings
  5. Clique em Instalar app e copie os tokens
🏪 Loja A
Origem

Onde os clientes compram. O checkout será interceptado aqui.

⚠️ Os tokens são salvos de forma segura no Firebase, vinculados à sua conta.

🏬 Loja B
Destino

Para onde os clientes serão redirecionados no checkout.

✅ A Loja B precisa ter os mesmos SKUs que a Loja A para o mapeamento funcionar.
